## Быстрый запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/talucre/RTK-Task-Tracker.git
cd RTK-Task-Tracker/
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Запуск проекта
```bash
npm run dev
```

### 4. Запуск тестов
```bash
npm run test
```

## Цель проекта
Фокус проекта сделан не на сложной бизнес-логике, а на качестве кода,
чистоте архитектуры и покрытии тестами.
В проекте используется упрощённая FSD архитектура, с разделением на:
* **app** - глобальные конфигурации, касающиеся всего приложения
* **shared** - код, который может быть использован любыми фичами внутри приложения
* **features** - директория, хранящая отдельные фичи, представляющие собой нечто цельное
В данном проекте только одна фича. Используется реэкспорт через index.ts в корне фичи.
Unit-тесты (в данном случае для слайса) лежат рядом с тестируемым кодом, а интеграционные,
Проверяющие работоспособность целой фичи, в папке __test__ в корне фичи.
Сами фичи разделены на ui (react-компоненты) и model (слайсы, типы)

## Использованные технологии
* **React + Typescript + Vite:** современный и удобный стек для разработки SPA-приложений
* **Redux Toolkit:** удобное хранение глобального состояние
* **Zod + react-hook-form:** для простой работы с формами и валидации 
* **Tailwind + tailwind-merge:** стилизация без необходимости переключаться между компонентами и их стилями, попадание только используемых стилей в сборку
* **vitest + jsdom + react-testing-library:** unit и интеграционное тестирование
* **Prettier:** для единого стиля кода во всём проекте
